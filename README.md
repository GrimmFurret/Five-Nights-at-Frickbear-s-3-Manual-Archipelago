# Manual Five Nights at Frickbear's 3 Randomizer
A Manual Archipelago randomizer for _Five Nights at Frickbear's 3_.

It allows for the "Randomization" of aspects in the game, such as Items, Upgrades, and Minigames using [Archipelago](https://archipelago.gg).  
These can be distributed across a Multiworld to enable items and progression to be shared across multiple different games.

## What can be Randomized?
- Salvage Level Access
- Mendo's Item Shop
- Minigames
- Ending-Based Items
- Upgrade Cadet's Upgrades
- Completing a Night with an Animatronic Active

## How do I play this Manual?
For this Manual AP, you start on Night One (this AP should be playable with any difficulty).
You are locked to Night One until you receive a "Level Unlock" item, which then grants you access to the first Salvage Location.  

Currently there is only one goal ***Complete the True Ending / Defeat Psycho Foe Fredbear***.  
This requires all 3 _Evil Ending_ items, all 4 _Animatronic Masks_, and _Talbert's Files_

## Requirements to Play
- [Five Nights at Frickbear's 3](https://gamejolt.com/games/frickbears3/930477)
- Archipelago (Website)
- Archipelago (Launcher)
- Archipelago (Manual Client)

## Archipelago Setup
1.) Download the [Archipelago Launcher](https://github.com/ArchipelagoMW/Archipelago/releases).

2.) Download the Frickbear's 3 Randomizer's most recently released .apworld file.

3.) Launch the Archipelago Launcher and drag the .apworld file into the client. Restart the Archipelago Launcher after installing the apworld.

4.) Create a .yaml file using Archipelago Launcher's in-built 'Options Creator'

5.) Place the .yaml into the Archipelago 'Players' folder alongside any other .yaml that you will be using for your Multiworld.

6.) Go back to the Archipelago Launcher and select "Generate". This will generate your Multiworld seed and place a .zip file into your Archipelago 'output' folder.

7.) You can then upload the zip to host the game as you wish. Archipelago's upload hosting page can be found [here](https://archipelago.gg/uploads).

8.) Connect using the [Manual Client](https://github.com/ManualForArchipelago/Manual/blob/main/docs/play/connect-client.md) on the Archipelago Launcher
